# Security

This repository holds Gather Rnd's plugin for AI assistants: instructions and the address of Gather Rnd's connector, `https://mcp.gatherrnd.app/mcp`. It holds no code that runs and no secrets.

To report a security problem in the plugin, the connector or Gather Rnd itself, email [info@gatherrnd.app](mailto:info@gatherrnd.app) with "Security" in the subject. Please don't open a public issue for it. We will answer, say what we are doing about it, and tell you when it is fixed.
