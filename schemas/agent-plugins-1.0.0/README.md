# Agent Plugins 1.0.0 schemas

Copies of the Agent Plugins 1.0.0 JSON Schemas, kept here so CI checks `plugins/gatherrnd/plugin.json` and `mcp.json` without fetching anything:

- `plugin.schema.json` from https://agent-plugins.org/schemas/1.0.0/plugin.schema.json
- `mcp.schema.json` from https://agent-plugins.org/schemas/1.0.0/mcp.schema.json

Fetched unchanged on 2026-10-04. They belong to the Agent Plugins specification, not to Gather Rnd; replace them with newer copies rather than editing them.
